BEFORE YOU START

你可能想知道。

查看完整使用文档 ↗
支持哪些系统？需要安装吗？+

目前支持 Windows 10 / 11 x64，暂未提供 macOS 和 Linux 版本。下载绿色版 ZIP，解压后运行 ntscreenshot.exe，无需安装程序或管理员权限。

不配置 AI，也能正常使用吗？+

可以。截图、标注、贴图、长截图、GIF、剪贴板历史和本地搜索不依赖 AI。AI 默认关闭，OCR 也需要单独启用并配置服务。

启动后没有窗口，或者快捷键没反应？+

程序主要驻留系统托盘，可右键托盘图标打开设置。快捷键可能被其它软件占用，在设置中更换一组即可。F5 截图，F6 贴图。

AI 助手能做什么？+

配置自己的接口后，可以进行对话，并按需开启联网搜索与网页读取。右侧浏览器支持 AI 点击、填表和滚动；遇到密码或验证码时交给你操作。关闭对话后，临时登录会话会清除。

下载后被系统提示为未知应用？+

当前便携版没有商业代码签名，部分安全软件可能给出未知应用提示。请从项目官方 GitHub Releases 下载，并按文档说明核实文件；无需关闭系统安全防护。
